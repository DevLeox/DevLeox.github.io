# DevLeox GitHub Profile Viewer 🌟

This project is a simple, responsive website 🌐 that showcases the GitHub profile and repositories of user **DevLeox**. By leveraging the GitHub API, it dynamically fetches user data 📡 and displays it in an intuitive and visually pleasing interface. 

## Features ✨
- Displays profile details, including avatar 🖼️, name, bio 📝, followers 👥, and following count.
- Lists repositories 📂 with details like name, description, and visibility (Public 🔓 or Private 🔒).
- Interactive buttons 🔘 to open repositories and view programming languages 💻 used in each repository.
- Sleek and responsive design for a seamless experience 🖥️📱.

## Project Directory 🗂️
DevLeox.github.io/  
├── index.html 🏠  
├── style.css 🎨  
└── script.js ⚙️  

## Technologies Used 🛠️
- **HTML5**: Provides the structure of the webpage.  
- **CSS3**: Styles the page for a polished look.  
- **JavaScript**: Handles API interaction and dynamic updates.  
- **GitHub API**: Fetches real-time profile and repository data.  

This project can be hosted easily on **GitHub Pages** 🚀. By placing the files in a repository named **DevLeox.github.io**, it becomes accessible at `https://DevLeox.github.io/`.
